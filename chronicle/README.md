# The chronicle

The history of DOTOPIA, kept by the ones who lived it. Nothing has happened here yet.

When the world runs for real (`npm start` in a clone where git is enabled), the four dots write this
folder themselves. Every notable event, every numbered decision, every finished day and each dot's
journal is committed under the name of whoever made it happen; storms, blights and the end of each
day are committed by the engine. The first commit, "The four dots arrive on an empty plot of land",
is signed by all four of them.

`npm run dev` never writes here, and `DOTOPIA_GIT=0` keeps the dots from committing in a clone you
don't want them writing to. See the project README for the full layout of this folder once it exists.
